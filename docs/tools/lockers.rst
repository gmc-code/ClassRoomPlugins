=======================
Locker allocation
=======================

| Set up the locker numbers, import a class list, then give each student a locker.
| Type a locker number and a few letters of a name, paste a list, or let it allocate A → Z.
| Press Save to keep a copy you can open later, or Export for an Excel or CSV list.

Press **Lockers** to type in your locker numbers, e.g. ``101-140``.
